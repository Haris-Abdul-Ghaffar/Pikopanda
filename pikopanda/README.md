# PikoPanda website
Plain HTML/CSS/JS. No build step.
1. Open `assets/site.js` and set `CFG.wa` to your WhatsApp number (e.g. "923001234567"), and edit hours.
2. Edit the `P` list in `assets/site.js` to add your real products. Put photos in `images/` and set `img:"images/photo.jpg"`.
3. Upload the whole folder to GitHub, then Settings > Pages > Deploy from branch (main, root).
